# Fixed Income+ Multi-Asset Allocation Research

A research codebase for 38 asset labels, nine-grid stock/bond regimes,
mechanical or optional LLM market views, risk budgeting, entropy pooling,
skfolio optimization, iTransformer forecasts and gated PPO execution.

## Current Status: 2026-10-20

This is an experimental research snapshot, not a production trading system.
The latest adopted convertible-bond accounting replay is V95. It completed
2,127 execution days through 2026-10-14, with 12 convertible-bond baskets.
Six securities were excluded by explicit retrospective research selection.
Those exclusions introduce selection bias and are not a pristine out-of-sample universe.

The current snapshot does NOT certify total-return NAV or new three-product
performance. Historical holding valuations and coupon/terminal cash flows
still require reconciliation. No fresh iTransformer/PPO training is claimed
for V95. Previously reported Sharpe ratios are historical experiments, not
validated performance of the current repaired dataset.

The abandoned V96 blanket exclusion experiment is not included or adopted.
Older versioned documents and configuration files are research history;
their descriptions of running processes or formal status may be obsolete.
In particular, `config/current_release.yaml` is an older historical registry,
not a statement of current certification. See `docs/PUBLIC_RELEASE.md` first.

## Download The Complete Dataset

After cloning the repository, run:

```bash
python scripts/download_research_data.py
```

This standard-library-only script downloads all ZIP parts and the manifest from
the [complete snapshot Release](https://github.com/tyyao989666/fixed-income-plus-allocation/releases/tag/research-snapshot-20261020),
verifies SHA-256 hashes and restores `data_raw/`, `data_processed/` and `output/`.
It refuses to overwrite differing local files. You can instead download all
`data-part-*.zip` assets and extract each into the repository root.

GitHub's Code / Download ZIP includes source only, not Release assets. No API key
is needed to download data; keys are needed only for subsequent provider/LLM calls.

## Quick Start

Python 3.12 is the locally used runtime. Historical dependency versions are not
fully locked, so package compatibility may require adjustment.

```bash
git clone https://github.com/tyyao989666/fixed-income-plus-allocation.git
cd fixed-income-plus-allocation
python -m venv .venv
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install numpy pandas
python examples/synthetic_demo.py
```

The example creates synthetic price and return CSV files and a small equal-weight
diagnostic. It does not reproduce the investment strategy or its historical returns.

For the broader research modules:

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p test_research_exclusions_v92.py
python -m unittest discover -s tests -p test_distress_exit_v94.py
```

Set provider credentials privately through environment variables. Never commit
real `.env` files or place credentials in source code. Provider account, SDK and
data-access permissions are separate prerequisites.

## Research Flow

```text
Licensed daily data + announcement evidence
  -> point-in-time alignment and publication/label maturity checks
  -> 38-asset features + nine-grid regimes + asset state cards
  -> risk-budget baseline and optional relative market/forecast views
  -> entropy pooling / skfolio constrained optimization
  -> gated PPO or mechanical execution
  -> T+1 execution, costs, corporate actions and cash-flow accounting
  -> ablations, audits and research promotion gates
```

This diagram describes the intended research chain. Inclusion of module code does
not mean all modules are enabled, approved, or validated in the current run.

## Real-Data Reproduction

The historical pipeline expects `data_raw/`, `data_processed/` and announcement
evidence described in its version-specific scripts. Restore the Release assets first.
Do not run `scripts/run_v1_full_pipeline.py` assuming it reproduces the latest
V95 accounting repair: it is an older entry point. V95-specific entry points are
listed in `docs/v95_six_cb_exclusions_20261020.md` and require their full input lineage.
Missing provider data or hash-bound evidence should block a run, not become zeros.
The snapshot manifest lists credential-related omissions and sanitizations.
Sanitized evidence may need reacquisition; do not bypass failed original hashes.

Repeatedly inspected 2024-2026 results must not be described as a fresh untouched
test set. Do not select parameters by those returns or relax failed gates to
improve reported performance.

No investment recommendation, return guarantee, or third-party data license is
provided. Repository visibility alone does not grant an open-source license;
no new license has been assigned in this upload.
