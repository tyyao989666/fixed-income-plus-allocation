# V58：公司行为事故后的全链路重建

## 最重要的更正

2026-10-16可预测性体检发现，V53/V55/V56/V57源数据中存在两个不合理收益断点：

1. credit_lgfv_aaa实际是511220.SH代理。2023-01-16未调整收盘价从95.318变为9.469，被重新pct_change算成-90.0659%。[交易所原始公告](https://www.sse.com.cn/disclosure/fund/announcement/c/new/2023-01-16/511220_20230116_F9OY.pdf)确认2023-01-13登记日实施1拆10。正确的拆分调整价格收益为9.469*10/95.318-1，约-0.65885%。拆分计划已于2023-01-10公告，不用未来收益猜因子。
2. credit_lgfv_aa的H11098.CSI代理在2026-05-15由26389.04变为250.5511，形成-99.0505%假跳变。尚未核验同口径指数因子，不按100或其他比例猜修。该日收益保持缺失，跨断点标签失效。

原始数据库在两日的return_1d本来就是NaN，后续构建却忽略已有缺失、从close重新计算，恢复了不应当成投资收益的跳点。仅验证相邻新旧来源重叠段、形状、哈希、时序与逆变换，不能证明历史公司行为正确。此前“预测审计通过”和模型增量不足的结论范围需要收窄；不能凭受污染评估认定算法不行。所有旧版本保留作取证，不用于晋升或迁移。

## 已完成的数据处理

独立目录corporate_action_v58保留38资产、日历与九宫格，修正一条有一手证据的拆分、屏蔽一条未核验基准断点，从收益重算全部局部特征、历史滚动标准化、相对收益标签、风险尺度和已成熟历史常态。不是在训练好的特征张量里替换一个数。

原始来源、旧NPZ及旧模型不改。全资产扫描当前仅发现这两条绝对单日收益超过25%的记录，修复后没有残留；25%是人工审阅触发线，不是对所有市场强行截尾的收益上限，也不能覆盖更小幅分红错误。完整票息、现金分派、代理可交易映射与成本仍未认证，不能宣称所有问题解决。

SSE PDF已通过web工具读取并核验；本地HTTPS下载遇TLS握手失败，所以缓存的是结构化一手证据摘录，不冒充PDF原始字节或其SHA。证据路径`data_raw/corporate_action_v58/reviewed_split_evidence.json`。尚未核验的AA断点完全没有补造官方来源。

## 执行顺序

1. 读取修复版并验证源哈希及极端收益筛查。
2. 在新目录从头训练iTransformer自监督编码器与F0/F1/F2/F3对照，2022–2026、三种子17/29/47、120日窗口、2层4头/d_model40、1000epoch上限及原早停、原T/V/G划分与门槛。F3保持此前预注册的总观点排序修正。绝不加载旧版本编码器。
3. 新编码器完成后，再在multitask_v58目录训练V57已设计的非线性条件均值、10/50/90分位数及下行风险头。此阶段冻结的是刚用修复数据重训的编码器，不是事故旧权重。
4. 对新多任务观点实施原预测门槛，审计均值与中位数分离、区间顺序、收益单位、标签成熟、源哈希和15任务产物。
5. 核验PPO执行授权；完整收益账本未认证则自动阻断正式PPO与晋升，不用旧数据运行凑结果。

多任务损失固定为日期/袖套均衡pinball + 0.20*总均值排序 + 0.25*未来自身回撤Huber + 0.10*均值MSE；期限权重0.15/0.50/0.35；资产和袖套任务各0.5。1000上限、至少50轮、每5轮验证、耐心40。条件均值和分位数均需因果逆变换，下行风险不加历史收益offset。未校准的分位区间不能包装成正确率。

## PPO职责不变

已有PPO每天判断hold或执行目标差额25/50/100%，不是强迫5/20/60日调仓。后者是预测期限。新执行观测接口接当期均值、区间宽度、风险、持仓偏离和成本，不接未来标签。证据门验证38资产、覆盖期、数据及证据SHA；预测通过也不自动授权正式PPO。

本次是数据修复后重训，不是反复挑2024–2026最好参数；这些年份仍不是未触碰样本外。没有真实新组合回测前不公布新的三产品收益/夏普。
