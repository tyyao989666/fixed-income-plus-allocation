# V63 成熟标签残差学习：固定研究协议

登记日期：2026-10-18。在实现和查看本轮结果前固定。之前2021/2022验证已用于V61/V62探索；本轮依然不是全新样本外，禁止包装为独立交易证明。

## 目标与边界

38资产、九宫格、120日输入、两层四头宽40的完整iTransformer保留。改变的是监督目标：用真实历史可见基准的收益残差训练，让预测的主要任务从资产静态排序转为增量收益。没有Agentic、外部行情、正式EP或PPO，不覆盖旧版。

训练及评估原2023/2024两折，三种子17/29/47，沿用V61的innerT/C/V划分及最大60日成熟隔离。随机初始化完整编码器，不使用已看过C的预训练权重。

## 基准严格如何生成

每个任务/期限/实体，查询日q仅从innerT来源行中选择：来源日早于q、距q不超过756个交易日、该期限label_end严格早于q且标签有效的记录。相同日期成熟的标签亦不使用，避免收盘可见时序争议。

各组先以每日有效实体均值再按有效日等权形成组均值，至少60个成熟来源日。实体至少60个成熟标签才使用自身均值，以n/(n+126)向组均值收缩；否则仅有组均值。没有足够历史则缺失，不用0收益填补。

innerT每行基准由该行之前已成熟标签生成，不能使用整段T标签回填。C/V也仅使用innerT来源行，不吸收C/V标签；756日历史窗口按查询日计算，旧标签可自然滚出，所以冻结的是学习来源而非人为声称预测值恒定。这是成熟时间约束的滚动对照，不是未来收益拟合器。

## 目标、尺度与损失

残差=原始累计相对价格收益-该行历史可见基准。每组/期限共享残差标准差，仅在innerT有效残差上拟合、最小1bp；C/V只应用，不按实体单独缩放改变组内收益含义。

神经网络输出经tanh约束在正负1个训练残差标准差内。主损失为标准化残差MSE；加0.05残差成对排序辅助损失及0.01增量平方惩罚。资产与袖套任务等权，期限权重0.15/0.50/0.35。对照为零增量，即不使用神经网络，只保留同一历史基准。

使用raw_relative_target及raw_relative_target_mask，并与原target_mask、有限值、历史基准可用性取交集。训练实体准入不得由C/V未来覆盖决定。资产始终保留在上下文；不符合标签支持的期限不能伪造监督。

## 校准、选择与停止

先将输出乘训练标准差，恢复累计原始相对价格收益单位。C按组/期限拟合0至1之间的单一非负收缩系数，岭0.1、至少100个有效日期。校准不回传梯度、不翻转方向，V不参与拟合。

每5轮评价V相对同一历史基准的收益MSE比，保留最低比值checkpoint；至少50、最多1000轮、40轮无改善早停，最小改善1e-4。C/V已研究使用的局限不因更换损失而消失。禁止以2024至2026收益挑参数。

6组固定实验，不换种子、不追加候选、不依据结果选择只保留收益好的资产。比较模型自身可用标签、与每个动量基准成对覆盖及四基准共同覆盖。收益MSE、横截面残差IC及收益观点IC分开报告。

下一阶段研究资格仍要求：每种子校准MSE不差于基准，每折集成收益观点相对各固定对照的RankIC增量至少0.01，资产/袖套增量观点种子一致性至少0.50/0.65。用相同基准带来的高一致性不能冒充神经网络一致性，所以一致性计算增量而非基准加增量。

即使通过也只允许继续研究；正式晋升和PPO仍要求独立收益/现金流/成本执行认证。失败正常报告，不自动搜索。

## 运行与审计

先完成成熟标签基准准备及断言、单元测试、GPU梯度烟测，再启动完整6组训练。源码/协议/配置/数据/标签和划分绑定SHA256；相同身份可恢复checkpoint，不兼容拒绝恢复。记录loss、验证指标、校准系数、来源最晚成熟日和覆盖。
