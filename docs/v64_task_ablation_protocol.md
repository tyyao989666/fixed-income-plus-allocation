## 数据与学习

重新构建历史基准，只允许F来源标签。每个查询日仅取严格早于该日成熟的F标签，756日窗口、60日组支持、60个实体标签、n/(n+126)收缩沿用V63；E/C/V不更新学习来源。残差标准差、特征裁剪、训练资格都只用F拟合，不复用看过E的V63尺度或裁剪结果。

F/E/C/V标签原始掩码、有限值与基准可用性共同限定。每实体/期限至少300个F标签才作为监督/评价合格资产，缺历史者仍在38资产上下文；各任务评价使用固定资格和相同模式间掩码。

loss沿用V63标准化残差MSE+0.05残差排序+0.01增量惩罚，预测边界正负1个F残差sigma，期限权重0.15/0.50/0.35。joint两任务等权；单任务把该任务权重归一到1，不把损失总量机械减半。未训练的头冻结且不加入优化器，不允许weight decay偷偷改动；其最终观点严格回到历史基准，不能导出随机头作为预测。

三种模式同一seed从相同随机模型权重开始、按同一F日期排列训练。任务可用标签不同导致有效梯度不同，必须如实记录，不声称经济意义完全控制。学习率、batch16、weight decay、梯度裁剪沿用V63。

## 选择、校准和停止

每5轮按E上的未校准原始收益MSE/历史基准MSE选择，joint按两任务等权，单任务按自身任务；目标任务不同的E分数不能直接互比。至少50、最多1000轮、40轮无改善早停，改善阈值1e-4。C未用于逐轮选择。

选中后，只对训练过的任务用C拟合0至1非负gain（岭0.1，至少100日），输出收益基准+gain×原始收益增量。F/E/C/V严隔离；F/E/C/V标签在文件中存在不等于可跨段调用，审计记录实际计算路径。

最终报告每mode×seed×task的F、E、V指标；横比单任务与joint必须是同一task、同一V标签支持。零增量历史基准、种子增量一致性及无标签覆盖均单列；未训练任务不参与模式优劣结论。单一2022年V不能得出普适结论，也不能据赢家晋升。
