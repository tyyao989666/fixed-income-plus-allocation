# V65 在线基准与九宫格稀疏性修复

2026-10-19，在生成本轮结果前固定。V64已知、原V已多次观察。本轮是基准层工程与诊断，不是新的全独立样本外检验；不据V挑参数，不训练网络或PPO，不修改旧数据或旧权重。

## 问题与改动

旧V64基准仅使用F来源标签，在E/C/V中不吸收后续已成熟的历史，可能不适应新环境。新基准允许每日吸收此前已成熟的标签，但任何样本未来5/20/60日标签，都必须在其label_end严格早于当前查询日后才进入。标签同日成熟亦延后一观察日；“当日有卡片”不意味着能知道当日样本的未来收益。

候选固定三个：旧frozen_mean（原V64存档）、新online_mean、新online_grid。两个在线版本使用完全相同的历史来源、756日最大窗口、126日信息半衰期、至少60个有效组历史日，区别仅是后者加入状态条件收缩。在线来源从F首日开始，包括后续隔离段/E/C/V中届时已经成熟的样本；与冻结版本的差异包含来源更新和时间权重，不能把其效果单独归因于指数权重。

权重按距标签成熟日的交易日距离计算，不按全样本统计量拟合。组均值先日内有效实体等权，再按日时间权重；实体估计向该组均值收缩。条件基准再以查询日股债单轴状态形成两个后验，等权混合，再将同一九宫格的实体历史向该单轴混合收缩。

各层收缩权重固定为ESS/(ESS+126)，ESS=(sum w)^2/sum(w^2)。这是时间权重集中度，不是校正标签重叠或序列自相关后的独立样本数，更不是置信概率。没见过/未知格子回退，不输出伪精确独立专家。

## 九宫格范围必须写清

训练数据现有九宫格来自rate_7_10y及equity_broad过去20日复合价格收益，强弱阈值分别+/-0.1%、+/-0.5%，同日收盘可见，下一交易日执行。它保留股债九格几何结构，但不是用户完整版宏观/估值/信用市场状态卡；后者未经历史可见性认证，不偷偷恢复到严格训练输入。

本轮重算九格、连续轴和掩码并与存档比较，逐格报告F/E/C/V样本数、连续出现区段数和实际标签支持。双中性全样本仅9日是事前已发现的稀疏性，不因此删除该格或改阈值。

## 评价与审计

沿用V64 F/E/C/V，实体/期限资格沿用其F内固定资格，不按后续完整覆盖筛选。模型上下文38资产保留。每对控制都使用相同日期/实体/期限掩码；报告原始累计相对价格收益MSE、横截面RankIC、可用单元和最新标签成熟日。

E作为主要诊断，C/V只作已观察研究描述，不将任何V优胜者晋升。总体MSE汇总只在任务内组/期限等权，再任务等权，不能用大波动资产的单元总MSE吞掉低波资产。分期限E连续60日块及尾块均报告，不将重叠标签误当独立显著性。

必须通过：未来/同日成熟标签篡改不变、前缀回放一致、未知状态安全回退、纯组均值与条件估计层次正确、缺失不补0、九宫格重建一致、原始文件哈希前后不变。审计输出明确区分“在线基准更新”与“神经网络重训”；本轮不产生组合收益或夏普。

## 后续接模型的契约

后续若接iTransformer：训练标签也必须由同一在线规则逐日生成，不能只在测试时换基准；缩放只能在神经训练段拟合；已成熟历史可更新确定性基准，不自动更新神经权重。E须包含零增量候选，E不胜出时用基准、不能强迫模型输出。

九格作为核心解释坐标继续保留；稀疏格用单轴/总体收缩，不用少量样本拟合九套大网络。正式EP仍接收益单位观点，正式PPO仍需单独完成现金流、终止事件及成本执行账本认证。
