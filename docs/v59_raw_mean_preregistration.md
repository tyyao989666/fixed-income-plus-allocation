# V59 原始收益均值对齐实验预登记

## 边界

保留38资产、九宫格及V58冻结iTransformer编码器，不重训旧模型，不改变V58门槛。仅使用2022、2023两折的历史T/V；不抽取G/test表征或标签，不以2024—2026表现选参数。年度拆分由实际V58数组重新计算，保留60日purge和标签成熟检查。

本轮模型只输出原始相对价格收益均值及10/50/90分位数；已完成V58的下行风险头保留在原版，但不混入本轮学习目标。下一步整合前须分别验证风险头，不伪称本实验已接入PPO。

## 两个固定候选

- linear：LayerNorm(40)后直接线性输出，均值与分位数独立参数。
- regularized：LayerNorm(40)→Linear(24)→GELU→Dropout(0.4)，均值与分位数分别输出。
- 两者均冻结各年度各种子自身的V58编码器，种子17/29/47；AdamW lr=0.0002、weight_decay=0.1、batch96。
- 最多1000轮，至少50轮，验证每5轮、patience40；保存每轮优化器/RNG与最优状态，按验证原始收益MSE相对F0评价早停。

## 目标与单位

直接使用asset/sleeve_raw_relative_target及真实成熟掩码，不再使用逐资产机会offset作为均值目标。仅在T上，为每个任务/袖套/期限估计一个共享均值与标准差，重复给组内实体；因此组内收益排序保持。该尺度只为数值稳定，反变换回原始累计相对价格收益，无年化、百分数或日收益隐式转换。不是已认证含息总收益。

损失按日期、袖套和5/20/60日权重0.15/0.50/0.35等权组织：1.0×均值MSE＋0.25×分位pinball＋0.05×原始收益排序损失。原始收益尺度保持组内共享，避免以不同资产尺度改变排序目标。

验证评价使用两候选与同折F0相同日期、实体、期限掩码；每组计算原始收益MSE/F0_MSE，等权汇总。另报横截面RankIC增量、多种子预测相关、80%区间覆盖。保留V58原预测头验证结果为参照，不直接比较不同损失函数数值。

候选仅在两折所有种子原始收益MSE改进非负、总体平均至少2%、每折集成RankIC增量非负、资产/跨袖套种子一致性分别达到原0.50/0.65时获得下一轮研究资格。并非正式晋升；若都通过优先linear；都失败则停止本轮，不加搜索或放宽门槛。任何后续全年度测试须另行冻结配置，已观察历史不冒充新样本外。

## 运行与证据

运行独立scripts/run_v59_raw_mean.py；输出output/models/raw_mean_v59和output/reports/raw_mean_v59。冻结数据、编码器及实现源码哈希。EP接口只接受带units/horizon/as_of/available_after/approval的原始收益观点，未认证或未批准一律拒绝正式执行，不自动下单、训练正式PPO或生成夏普。

账本只读整合本地来源，实际付款记录与合同计划分开；保留出处、来源哈希、公告/除息/付款日期及未知项。无独立核验时不创建execution_certificate.json。
