完成的是“独立重建研究锚点、移除旧参照依赖、整理基金分派证据”，不是整个策略已修完或训练已通过。

## 1. 原实现的问题

- `src/v1_strategy.py:build_sleeve_returns` 最终会将缺失袖套收益填成0；偏好资产聚合还会丢掉缺失成员后重新归一。它们可能扭曲波动率、协方差及成员构成。
- 原风险预算迭代在达到最大次数后直接返回权重，没有对收敛或风险贡献误差给出成功/失败契约。
- 历史不足时把目标风险贡献投影为资本权重。这是一种启发式，不是已求解的风险预算。
- V74仍沿用旧V44的组合参考权重。即使修正收益输入，参照的来源链也没有因此自动修复。

这些旧文件保留，不在本轮静默重写，方便复核旧结果差异。

## 2. V75新锚点如何生成

输入：V74修正后的38资产日收益、原 `config/v1_strategy_config.yaml` 中的三产品预算、上下限及袖套内偏好权重。没有读取旧市场卡、预测或V44锚点。

1. 每月初使用上月最后一个国内交易日收盘时已经可见的资产可用性，确定袖套内成员与偏好权重。尚无数据的资产不会提前进入。
2. 当月按这些起始权重计算买入持有研究收益，期间自然漂移。不因后来缺报价而删掉成员，不对幸存资产重新归一。任一持有路径缺失，整个月袖套收益保持缺失。
3. 仅使用截至信号日最近36个日历月，取五袖套同时完整的月份估计协方差。至少12个完整月份；不足时不生成锚点，不把未知收益填0。保持原20%对角收缩及0.002月度波动下限设置。
4. 最小化风险贡献份额与目标份额的平方误差，约束资本权重合计1、非负及原袖套上下限。使用解析梯度、SLSQP及4个固定数学初值；不据测试收益挑起点或调参数。
5. 要求求解器成功、预算/边界残差合格、投影梯度残差不高于1e-4。记录每个起点、目标误差及协方差最小特征值。多初值并不证明全局最优。
6. 信号于实际月末最后交易日收盘形成，执行日期标为下一国内交易日。10月14日仍属未完整月份，所以月度估计截止2026-09-30。

研究输出不是可执行库存净值，不包含对全部分红、退出、冻结库存与成本的认证。

### 尚未解决的预算冲突

所有产品锚点都没有在1e-6精度内精确达到目标风险贡献。每期“最大袖套风险份额偏差”的均值，低/中/高约为24.59 / 20.09 / 17.44个百分点。高波权益资本权重在这次样本中始终贴17%下限；中波权益也接近下限。约束与风险预算目标存在明显张力。

本次未证明这些目标在全局上不可行，也没有擅自放宽约束；只能如实报告当前有约束解未达到目标。相同输入下，新求解器的风险预算平方误差没有差于旧迭代器，但这不等于收益提高。

`equal_risk_same_bounds` 只是相同产品边界下的等风险目标对照，不是真正精确的等风险贡献组合。后续正式对照必须另列不受这些产品边界限制的经典ERC基准，不得混名。

## 3. V76基金现金流证据

通过本机Tushare配置，逐只获取7个ETF和9个REITs的基金分红记录。16只查询均成功，原始响应缓存、请求身份和哈希已保存；没有重复请求已经成功缓存的数据。

截至2026-10-14可见的实施方案去重后有171个合格除息研究事件，其中144个除息日在2018-01-02以后。其余是同一基金更早历史，不应把171个都称为本回测期内分红。

处理约束：

- `known_at=max(公告日, 实施公告日)`，不得在公布之前使用方案。
- 同一经济事件只计一次。现金金额或支付日期冲突则标记、阻断，不相加。
- 实施状态、登记/除息/支付日期顺序及每份现金都检查。
- 派息计划日期不作为实际到账确认；分配收益基准日不是当时信息可见日。
- 4只ETF接口返回空记录，明确标为“空来源不等于已认证无分红”。拆分仍须独立认证。
- 新提取的9只REITs除息现金与冻结V53现金表无差异，但这只支持去重/日期抽取一致，不证明库存、支付和自融资正确。

字段说明采用[Tushare fund_div官方文档](https://tushare.pro/document/2?doc_id=120)。它提供分红日期和每份金额，不是账户结算回执。本轮没有把这批记录直接加到价格收益上，避免与拆分、应收款或既有指数派息重复。
