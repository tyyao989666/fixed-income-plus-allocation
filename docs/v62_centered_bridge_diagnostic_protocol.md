# V62 固定模型接口诊断协议

日期：2026-10-18。V61验证结果已知，本协议不是事前未接触样本外实验，不用于模型晋升。

## 固定范围

不训练、不选新checkpoint、不改V61源或数据、不接Agentic/PPO、不抓行情。保留38资产及九宫格。使用V61已选中的两折三种子模型；它们通过V选择，因此V上的所有结果仍为探索性研究。

## 唯一接口变更

按当日可见输入的资产可用性与inner T至少300个成熟标签的资格，在各组/期限内对分数减去当日组均值。可用性由当日local_masks及inner T计数决定，绝不由V未来收益是否缺失决定。组内不足2项则增量为零。袖套为5类袖套间居中。

只在原C上拟合非负残差斜率：目标为原始相对价格收益减T先验，岭系数固定0.1，至少100个具有两项有效标签的C日期。零斜率分为历史支持不足、无分数分散度、关系不支持正斜率三类，不能都叫模型无效。收益观点=T先验+斜率×居中分数。按种子平均收益观点，不直接平均原始分数。

标准化与分数中心化不同：本轮不新增基于V统计量的标准化、不修改输入特征。只用C拟合收益单位斜率；当日横截面居中不拟合未来数据。

## 评价覆盖

分别输出模型全部合格标签、模型与各基准成对共同覆盖、四基准共同覆盖。每一对比较的模型与基准必须使用同一掩码。不将不同覆盖宇宙的IC横向相减；不根据结果挑宇宙或删除资产。

统一报告组×期限的IC、同掩码IC增量及收益观点相对先验的MSE比；无量纲分数不计算收益MSE。总览只对有效任务/期限/组分层平均，同时报告组成数量，不和V61不同权重的总IC混用。无有效排名/零先验MSE时输出缺失而非伪造改善。

## 审计与停止

执行前后校验V61 manifest；记录6个selected.pt及存档预测的哈希。先复现原V预测，超出rtol=1e-4/atol=1e-5则停止，不能把不一致的推断当接口效果。输出标注非交易观点、未经独立样本外检验，无论提升与否都不放松V61门槛。完成一次诊断即停止，不自动试其他校准系数。
