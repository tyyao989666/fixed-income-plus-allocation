# 完整数据下载与运行

## 一、下载代码和真实数据

```powershell
git clone https://github.com/tyyao989666/fixed-income-plus-allocation.git
cd fixed-income-plus-allocation
python scripts/download_research_data.py
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python scripts/check_downloaded_snapshot.py
```

下载器只用Python标准库，按清单下载全部数据分包并核对SHA-256，恢复原始数据、处理后数据、历史模型和报告。正常的Code→Download ZIP只有代码，数据在Releases附件里；也可将所有data-part-*.zip分别解压到项目根目录。

需要额外磁盘空间存放压缩包及解压数据。已有同名文件且哈希不一致时下载器会停止，建议使用全新目录。下载现有公开数据不需要API密钥。

## 二、不调用API的历史研究流程

恢复数据并安装依赖后，可以显式运行旧版机械基线流程：

```powershell
python scripts/run_v1_full_pipeline.py --skip-data --skip-market-skill --skip-itransformer-ppo --workers 3 --strategy-version no_agent
```

这个命令会重新生成旧版三产品基线输出，覆盖对应生成文件。它不是最新V95的完整修复后回测，不会训练新的iTransformer/PPO，也不认证旧版收益。不要把能运行当作策略有效。

V95转债执行账本回放入口见`docs/v95_six_cb_exclusions_20261020.md`。有来源哈希门控的流程必须先通过原始证据核验；公开包中清理密钥造成的证据变化不能通过放松门控绕过。

## 三、接自己的API继续研究

将`.env.example`中的变量配置到自己本机环境，不要提交真实密钥。脚本对`.env`的读取方式并不完全统一，优先显式设置环境变量。下载数据和查看报告无需API；重新抓行情或启用LLM才需要相应权限和密钥。

数据提供商SDK、Wind终端、GPU及PyTorch CUDA环境需要各自安装；`requirements.txt`未严格锁定历史版本，异机运行可能需要处理兼容性。

## 四、当前限制

截至2026-10-20，采用V95六只券剔除研究口径，保留38资产、九宫格和12个转债篮子。剔除存在事后选择偏差。估值、普通付息和兑付证据仍有缺口，不能承诺“只填密钥即可得到已认证的新夏普”。历史模型与结果包含被隔离、失败或已撤回的实验；V96大范围剔除未采用。

原始数据公开依据为所有者明确授权。数据包不包含API密钥，不包含本地虚拟环境，也不重新打包旧版重复分发ZIP。
