# V66：估值边界的核验与接入协议

## 思路与接入位置

保留38资产、股债九宫格、iTransformer相对观点、EP/skfolio以及后续PPO设计。新增的是估值环境坐标，不是替代九宫格，更不是遇到极端估值就直接反向交易。

流程：日频原始数据 → 来源/可见时间检查 → 九宫格与原有特征，同时计算独立的月频估值边界 → 按上一完整月映射至每日 → 带缺失掩码的iTransformer宏观输入 → 相对观点门控 → EP/skfolio → 经认证后才可训练的PPO执行。

本次只完成边界模块、研究特征和严格掩码数据接口；没有重训、没有运行新组合回测。未认证的边界输入保持掩码关闭。不能把“代码接入”写成“模型已经利用该信息并提高夏普”。

## 原论文核验

Hjalmarsson与Suominen，Boundaries of Time-Series Momentum，Financial Management，2026年7月6日首次在线发表。
原文：https://doi.org/10.1111/fima.70055

美国研究使用股息率或CAPE，以及长期国债收益率减短期无风险利率；国际研究覆盖20个国家，使用股息率和五年政府债券相对本国无风险利率的期限利差。其主要对象是股票市场的时间序列动量。

计算先做12个月移动平均，再使用过去10年或20年的历史范围缩放到[-1,1]，两个坐标平方求和。本文实现明确把历史极值作用在平滑后的序列上，当前已知月也包含在历史范围内；这一实现解释应在复现原文时披露。

```
ma_x(t) = mean(x[t-11:t])
lo_x(t) = min(ma_x[t-H+1:t])
hi_x(t) = max(ma_x[t-H+1:t])
scaled_x(t) = 2*(ma_x(t)-lo_x(t))/(hi_x(t)-lo_x(t))-1
Boundary(t) = scaled_dividend(t)^2 + scaled_curve(t)^2
H = 120 或 240 个完整月
```

Boundary范围[0,2]。它不是z-score平方，也不是过去24/36个月标准化。两个方向上的极端都会得到较大数值，所以同时保留两个有符号坐标，避免丢掉贵/便宜、曲线陡/平的区别。分母为零、缺月或历史不足时保留未知，禁止按中性零值解释。

10年边界需要131个原始月，20年需要251个月；不能把短样本悄悄缩短成另一套公式。本文所取2005年4月以来的数据，20年版本仅在样本尾端可计算，不适合充当全历史核心输入。

原文讨论的是边界与动量的条件关系，不能由此推断所有资产都应翻转趋势。原文短周期证据也较弱；不能直接把月度结论当成未来5/20/60交易日的可交易优势。原文附录还提示部分样本外可预测性集中在特定年份，必须检验跨时期稳定性。

## 本项目的中国适配与限制

1. 股息率：沪深300历史股息率，iFinD返回字段为“股息率”，单位百分数。请求TTM不代表返回字段已经获得TTM认证；当前元数据没有证明TTM、历史成分股处理和历史修订口径。
2. 曲线：中国债券信息网中债国债10Y-1Y收益率，单位百分点。这是中国适配，不是原文国际样本的5Y减无风险利率。
3. 日历：沪深300“收盘价（不前推）”非空日期；对照本地修正数据交易日，周末不填价格。月末用该月最后实际收盘日的同日股息率和期限利差，不跨日补数。最新不完整月不用。
4. 动量交互：沪深300过去252个交易日价格涨幅，不是含分红、扣无风险利率的原文超额收益。名称明确为price momentum。
5. 可见时间：每日只取上一个已完整结束的日历月，禁止用当月最终数据给月内历史日赋值。但这一保守滞后不能证明供应商历史值未修订，不能替代PIT来源认证。
6. 来源没有认证时，研究值可以展示；严格模型值为占位0并且mask=False。0不代表中性。不能将这些研究值加入正式预测或PPO奖励。

## 输入与输出

输入原始响应及CSV：`data_raw/boundary_v66/`，保留供应商返回原件，不从截断的Markdown预览拼接数据。

`scripts/build_v66_boundary.py`读取修正后的V58数据，核对SHA256，生成：

- `output/reports/boundary_v66/monthly_inputs.csv`：实际月末观测日期、股息率、期限利差。
- `monthly_boundary_120m.csv`与`monthly_boundary_240m.csv`：两种完整窗口边界。
- `daily_boundary_state.csv`：映射后的日频研究值、所属观测月份、可用性标记。
- `market_boundary_cards.jsonl`：每天的补充市场状态卡，保留原九宫格编号和38资产数量；不替代原38张资产卡。
- `coverage_by_year.csv`和`status.json`：覆盖、阻塞、因果前缀检查、来源与产物哈希。
- `data_processed/boundary_v66/research_boundary_features.npz`：研究值和严格/研究双掩码，不供正式训练直接读取。
- `data_processed/boundary_v66/dataset_strict_masked.npz`：原数据全部保留，宏观通道追加5维；未认证新维度严格关闭。

追加5维：股息率有符号坐标、曲线有符号坐标、Boundary、Boundary×过去252日价格动量、Boundary×该动量绝对值。它们均为无量纲状态变量，不是收益率。

新通道改变输入维度，未来需要独立重训及校准，不得直接套用旧checkpoint。实际训练前应核查宏观通道是否动态取维度，不能仅改文件名。

## 本轮预先固定的低成本增量诊断

不立即为一个尚未认证的特征重训大模型。先在V64原有F/E/C/V划分上做研究性线性探针：F427日拟合，E/C/V各126日分别展示；V此前已观察，不作独立样本外。固定ridge惩罚10、截距不惩罚，标准化仅拟合F，不搜参数、不调边界阈值。

对照依次为F实体历史均值、过去252日宽基价格动量、动量加边界及两个有符号坐标、再加两个交互项。目标仍为原38资产数据中的5/20/60日原始相对价格收益；评估仅取权益组内资产及权益袖套，避免把股票论文泛化成所有资产反转。

每个实体/期限仅使用F已成熟有效标签，F全部标签截止必须早于E首日。比较采用共同日期/实体/期限掩码，逐日先均衡实体再均衡期限；权益组内报告每日横截面RankIC，单一权益袖套不伪造横截面RankIC。该探针不涉及组合收益、成本、夏普或正式晋升，即使E改善也不能绕过股息率认证与后续神经网络消融。
