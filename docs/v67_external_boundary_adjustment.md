# V67：跨对话旧回测的会计复核与迁移方案

## 先对齐对象

旧成果位于另一个对话“阅读量化交易周报文章”，其脚本为run_individual_boundary_tsmom.py。它对历史截面上的每只股票和转债分别计算25种月度动量投票，再用共同市场Boundary调整每只证券的多头比例。这与V66线性探针、38个代理资产的组内相对收益预测不是同一实验。旧结果不能被V66失败直接否定，也不能当作本项目iTransformer或PPO的成功证据。

## 固定会计复核

保留旧目录和结果，仅读源文件。固定Boundary阈值1、窗口24/36个月；A股单边20bp、转债30bp，保留base/flip/soft_flip三条，不新增寻优。所有结果完整输出，不按结果挑赢家。

重建旧口径，以及不前向填价格的口径；每种均报告旧半L1成本和考虑持仓漂移的全风险资产成交名义成本。股息率、国债10Y减1Y Shibor沿用旧来源，避免同时换成V66数据导致无法归因。

所有信号在月末t形成，仅赚t+1的收益。完整现金流、除权、停牌/退市/赎回所得及真实成交未认证时，任何数字都只是研究情景。缺失持仓收益按风险资产收益0的情景计算，同时逐月披露未知权重，不能把它称作保守估计或严格净值。严格完整样本结果在未知退出价格解决前不发布，也不能删去这些月份再冒充完整策略业绩。

单位成本应乘实际风险资产买入与卖出金额之和；半L1适用于某些单边换手报告约定，不能不加说明地与单边成交费率混用。逐月从价格漂移后的持仓到新目标计算成交，不只比较两个目标。当前诊断忽略上一月交易费融资导致的微小权重漂移，非正式交易账本。

另外固定展示剔除2024年9月的事件依赖诊断。去掉一个月后重算的结果只是压力测试，既不是可交易策略，也不能据此临时取消当月交易。网格中6个设置全部获胜是参数敏感性表现，不是6次独立实验，更不是100%未来胜率。

## 数据根因优先级

1. 原monthly表为close/pre_close/vol/amount，不能证明close已复权或含现金流；股票除权和转债付息/赎回须重新核验。pre_close是上一交易日价格，不能直接当成上月末价计算月收益。
2. 原pct_change默认前填可能跨过缺失月份。改成fill_method=None并检查完整月历，不用缺失后恢复价格生成虚假的单月收益。
3. 对已有持仓，月末无成交不等于可以零价、现金价或已知价格退出。必须区分停牌继续持有、缺报价待核、赎回结算、退市终止。未知状态要阻断正式账本。
4. 股息率口径与修订历史未认证；月末信号映射到次月只解决索引因果，不自动证明历史数据未修订。
5. 最终原个券数据截止2025-03，不能写成2026年最新回测。原代表参数样本比整套项目短，不混用。

## 如何迁移进固收+

保持38资产与九宫格。把有效假设分成三个互不替代的部分：每资产的连续趋势投票、共同估值环境、边界与趋势的交互。九宫格仍是股债状态坐标；个资产投票描述其自身趋势，估值边界不替代它们。

先对38资产构建共同可用掩码的机械基准：风险预算底仓、底仓加趋势相对排序、再加边界软调整。缺失Boundary不得按0解释，不可用时回到不含边界的规则。不把旧全市场个券结果直接赋给38代理资产，也不把投票分数直接当预期收益。

旧策略未投部分赚现金；本项目用户要求无现金，不能照搬。候选迁移只对当前合法主动偏离做收缩，再由同一受约束优化器在合格袖套中再分配，维持满仓及产品上下限。不设固定50%现金，不自动用1-p硬反手，不自动指定所有资金去30Y或黄金。

低波保持较小主动偏离、中高波使用各自既有合同约束；不因这次回测重新按已观察年份收益调整产品上限。先证明收益观点的有效性，再讨论风险层级，不用加杠杆掩盖信号无效。

iTransformer负责学习这些状态是否具有条件预测力。预期收益仍需F拟合尺度、E早停及零增量候选、C收益校准和成熟标签隔离；只有合格的收益单位观点交给EP/skfolio。PPO只控制是否执行/执行幅度，输入当前趋势、边界可用性、偏离和成本；在现金流及交易账本认证前，不启动正式PPO奖励训练。

下一轮必须在同一数据、日期、成本、掩码和产品约束下比较，并预登记方案；不得利用已反复观察的2024–2026挑阈值，然后再称未见样本外。迁移是待验证的策略设计，不是本轮已完成的正式收益提升。
