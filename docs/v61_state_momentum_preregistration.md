# V61 状态条件化动量与端到端排序：预登记

## 研究问题与范围

不继续V59/V60失败搜索。本次检验经济结构明确的假设：在多尺度动量及九宫格条件下，直接监督训练iTransformer能否比动量/收益先验得到更可靠的相对排序。保留38资产，原版不覆盖，不发布组合收益、不启动正式PPO。

## 与文章的关系

参考《Boundaries of Time-Series Momentum》https://doi.org/10.1111/fima.70055 的条件化动量思想，不宣称原论文复现。原论文是市场层面，长期估值边界；本地38代理资产、短历史和净价研究口径不同。

基线采用1/3/6/9/12月动量与同组持有期的25种历史cohort投票均值。仅完整历史月参与，缺观察不当0；月末信号到下一交易日可用。此处投票是观点特征，不是现金头寸或已执行收益，不把全仓约束偷偷改成持有现金。

目前沪深300历史股息率/指标口径及真实可见日期尚未核验，Boundary默认不可用；红利指数价格、PE均不替代股息率。iFinD2015年探测虽HTTP成功，但返回335条而非12个月末记录，存在日历日及指标参数元数据疑点，原样隔离。期限利差有本地候选，但未与缺失股息率拼成假Boundary。

另设明确命名的价格过热规则：20日累积收益/(20日历史日波动×sqrt(20))>2且252日自身价格收益>10%时，将动量投票向0.5收缩一半；仅作用权益、转债。它不是价值Boundary、不是原论文flip，也不是实际50%现金仓位。其余规则不搜索阈值。

## 时间分割与对照

只用2023、2024两折的历史T/C/V。这里2024折验证发生在2022年，不使用2024—2026测试收益。

从原T末端留126个日期为C，C之前隔离60日标签再取innerT；必须至少300日。2022折不足因此不纳入，不缩短purge凑样本。V沿用原126日验证，C标签必须在V第一日之前全部成熟。

iTransformer从随机初始化完整监督训练，仅innerT参与反向传播；不使用曾见过C窗口的预训练编码器。2层4头、宽度40、120日序列；局部及全局编码器、宏观/袖套投影均参与梯度，重构头/旧输出头不训练。innerT拟合神经输入裁剪界限。

相对排序采用pairwise logistic损失（RankNet思想，https://www.microsoft.com/en-us/research/wp-content/uploads/2005/08/icml_ranking.pdf），直接按原始未来相对收益符号成对比较，非逐资产缩放标签。损失按日期/袖套组织，5/20/60日期限权重0.15/0.50/0.35，加0.001分数平方惩罚；不是原论文保证金融收益的证据。

对照固定为T收益先验、20日动量、25组合月度投票、价格过热修正投票。每项评价必须使用模型和全部基线共同有限的日期/实体/期限掩码，单列覆盖，不借上市后完整窗口筛选历史投资名单。

innerT内每实体/期限至少300个有效标签才开放该实体监督与验证评价；不足者保留38维上下文和原始缺失掩码，不以其未来覆盖倒推准入。C内某组/期限不足100个有效横截面日期时，收益校准斜率保持0，不能用少量记录制造精确观点。

## 校准与选择

排序分数是无量纲，不能直接交EP。C上单独拟合任务/袖套/期限共享的非负斜率，将分数转换为相对T收益先验的原始收益增量；岭强度0.1固定。原始均值为先验＋斜率×分数。C不用于梯度，V不用于拟合校准器，负斜率归0而非倒转排序。

每5轮按V相对最强固定基线的平均RankIC增量选择权重，patience40、至少50/最多1000轮。V用于选模型，因此导出的V预测只能作事后诊断，不能回填当期交易。

三种子两折完成后，仅当每个种子相对所有基线RankIC增量非负、每折集成增量至少0.01、校准后均值MSE不差于T先验、多种子资产/跨袖套一致性不低于0.50/0.65，才获得下一阶段研究资格。原正式组件门、成本和PPO账本认证不变。失败即止，不换种子或扩大候选。
