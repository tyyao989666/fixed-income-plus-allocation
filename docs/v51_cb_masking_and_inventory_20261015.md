# V51 转债事前资格、标签屏蔽与冻结库存

## 本轮改动

保留原来的 38 资产上下文、12 个转债桶、九宫格及 iTransformer/PPO 研究框架。不追溯删除问题券、不删除包含缺价的整个交易日，不替换原模型数据和绩效。

1. 买入资格只读取信号日收盘时已可见的价格、成交量、已公告余额、发行规模及已知退出限制。缺失或非正数不允许新买；未知退出状态也不允许新买。信号日成交不能保证下一日能成交。
2. 下一交易日缺价不会改变上一日的候选和目标；持有成分缺收益则该桶研究收益未知，不重新归一化幸存券。
3. 每个资产独立生成未来 5/20/60 日绝对收益标签及布尔 mask。任一必要未来观察缺失则该资产、该预测窗口 mask=False；保留日期和其他资产。数组中的零仅为无效标签存储占位，训练必须使用 mask。
4. 原相对标签仍须固定信号日基准成分。基准成分缺失会连带使相关相对标签失效，这是基准依赖而非整行删除；禁止未来筛选或重新归一化基准。本轮产出的绝对标签不是原相对预测目标的静默替代。

## 库存接口

`src/v51_cb_policy.py` 中 `Inventory.close_step` 接收上一信号产生的目标、上一信号买入许可、当日真实执行价格/可成交标记和独立估值标记。调用方必须保证时点与来源；接口自身不能认证供应商证据。

- 按数量维护持仓；无成交证据不能卖出，也不按目标权重假设退出。
- 收盘交易只影响之后的持仓，不能让新买入仓位赚取交易前的收益。
- 无成交估值只用于估值，不授权成交；无可靠当期估值时保留最后价格作为临时参考，但 certified_nav 为 NaN，不能把它变成零收益。
- 恢复报价时按实际新价重新估值，停牌前后的损失不会消失。
- 先卖后买，双边成交额各收 5bp，未成交不收费；买入按可用资金缩放，不隐含借款。
- 结算现金不是新增“现金配置产品”。冻结和费用导致的残余必须真实记账，不能强行归一到 100% 已投资。

## 已运行与未运行

生成脚本：`scripts/build_v51_cb_masked_research.py`。

产物：`data_processed/cb_masked_research_v51/` 下事前买入资格、12 桶研究价格收益、标签及 masks；`output/reports/cb_masked_research_v51/` 下资格原因统计、分桶事前审计、逐资产标签覆盖和带来源哈希的 status.json。

该脚本不联网、不删原数据、不训练模型、不计算正式组合夏普。日期来自 V50 转债源，2018-01-02 至 2026-10-14；其余 26 资产并未因此自动更新。研究收益逐日重建目标，不等于冻结库存的可执行收益。

单元测试：`scripts/test_v51_cb_policy.py`，覆盖 38 维 mask 隔离、成熟标签未来扰动不变、停牌持仓数量、缺估值、无成交标记、复牌损失及真实成交成本。

本轮实测：9 项 V51 测试及 10 项 V50 证据回归测试通过；25,524 条事前分桶审计记录的日期顺序、权重和为 1、单券不超过 10% 均通过。标签数组为 2,128×3×12，5/20/60 日分别有 25,291 / 24,608 / 22,964 个有效绝对标签。缺失桶日共 49，其中首日无上一交易日信号占 12，之后 37；这些是“桶×日期”数量，不是独立缺失证券日数。未通过补零或事后剔除获取完整收益。
